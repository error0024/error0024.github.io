We introduce the aborting random oracle model (aROM), which extends the random oracle model to hash functions that may abort on some inputs. We prove security bounds in this model and give generic indifferentiability results showing how to build aborting random oracles from standard ones, so that these bounds carry over to the standard random oracle model. We apply the framework to SNARK-friendly incomparable hypercube encodings for hash-based signatures and to the analysis of grinding in Fiat–Shamir non-interactive arguments.
